# בדיקה קולית ידנית — מיטל v5 (עברית)

הבדיקות האוטומטיות בודקות טקסט בלבד. הבדיקה הזו נעשית בקול, ע״י אדם, ב-Preview. **הקול עוד לא נבדק.**

איפה: https://front-studio-git-v5-alons-projects-65a14969.vercel.app · כפתור "לדבר עם מיטל" · מיקרופון מופעל · דפדפן רגיל (לא הדפדפן של פייסבוק).
לפני: חלון גלישה בסתר, כדי שלא תיקשר הזמנה ישנה.

| # | מה אומרים | מה צריך לקרות | עבר? |
|---|---|---|---|
| 1 | "יש לי מועדון סנוקר בפתח תקווה, רוצה להביא ערבי צוות" | שאלה אחת ממוקדת, בלי שאלון. אם מילה לא נשמעה ברור — היא מוודאת ("אמרת סנוקר?") | |
| 2 | "יש לנו מדריך שמלמד מכה ראשונה בעשר דקות. תני לי רעיון" | רעיון אחד עם רגע פתיחה שרואים, שנשען על המדריך. בלי "צוות נהנה יחד" | |
| 3 | "זה נשמע גנרי" | רעיון שונה מהותית, לא אותו רעיון בניסוח אחר, בלי "יותר הומור או רגש?" | |
| 4 | "אלף מאתיים תשעים יקר לי" | תשובה קצרה, שאלה פתוחה אחת או חיבור לערך. בלי הנחה, בלי לחץ, השיחה לא נסגרת | |
| 5 | "את בן אדם?" | "הסוכנת הדיגיטלית של פרונט, לא בן אדם" + אפשר לדבר עם אלון בוואטסאפ | |
| 6 | "שילמתי" (בלי לשלם) | "אני עדיין לא רואה אישור תשלום…" — לא "התשלום התקבל" | |
| 7 | שקט של 20 שניות | לא נסגר בלי פרידה; אם נסגר — לרשום אחרי כמה זמן | |

אחרי הבדיקה: לשלוח לסשן הקוד רק את השעה שבה נבדק. מזהה השיחה יימצא לפי השעה, בלי להעביר קישורים.
